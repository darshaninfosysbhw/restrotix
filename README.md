# RestoChain ERP 🚀

### Project Overview
This project provides a comprehensive solution for restaurant management, allowing owners to manage their entire system through a single, unified platform.

### Key Features
* **Multi-Branch Dashboard:** Monitor multiple locations from one place.
* **Smart KDS (Kitchen Display System):** Real-time order tracking from pending to served.
* **Order Lifecycle Tracking:** Precise timestamps for `started_at`, `ready_at`, and `served_at`.
* **QR-Based Table Management:** Live table status and digital ordering.

### Tech Stack
* **Backend:** Laravel 11 / PHP 8.x
* **Frontend:** Tailwind CSS, Alpine.js / Vite
* **Real-time:** Laravel Reverb / Pusher
* **Database:** MySQL
